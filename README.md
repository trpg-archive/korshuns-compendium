# 🐺 Shared Compendium 🦅

Модуль-компендиум для **Foundry VTT** и системы **D&D 5e**, в котором собраны настроенные для игры сущности, заклинания, предметы, особенности и справочные материалы.

> Проект находится в разработке: содержимое паков, настройки автоматизации и структура данных могут меняться от версии к версии.

## Что входит в модуль

### Для игроков

- **Персонажи**
  - Классы и подклассы
  - Расы
  - Особенности персонажей
  - Происхождения
- **Заклинания**
  - Заклинания
  - Призывные сущности
- **Предметы**
  - Снаряжение
  - Магические предметы
  - Зелья
  - Оружие
  - Доспехи
  - Инструменты
  - Транспорт
  - Товары

### Для мастера

- **Бестиарий**
- **Особенности монстров**
- **Ширма Мастера**
- **Таблицы**

## Совместимость

Модуль предназначен для **Foundry VTT** с системой **dnd5e** и ориентирован на правила **D&D 2014**.

В `module.json` заявлена совместимость:

- Foundry VTT: минимум **v12**
- Проверено до **v14**

Основная разработка и тестирование ведутся на актуальных версиях Foundry VTT 13–14 и dnd5e.

## Зависимости

Для полноценной работы модулю требуются:

- **Midi-QOL**
- **DAE (Dynamic Active Effects)**
- **ATL (Active Token Lighting)**
- **Vision 5e**

Часть сущностей и эффектов может использовать возможности этих модулей для автоматизации.

## Установка

В Foundry VTT откройте установку модулей по ссылке-манифесту и вставьте:

```text
https://github.com/trpg-archive/korshuns-compendium/releases/latest/download/module.json
```

Foundry скачает актуальный релиз модуля автоматически.

## Изображения

Изображения **не входят в установочный архив модуля**. Они хранятся отдельно в этом GitHub-репозитории и загружаются Foundry по прямым ссылкам.

Благодаря этому сам модуль остаётся небольшим по размеру, а пользователю не приходится скачивать всю библиотеку изображений вместе с паками.

Для отображения изображений требуется доступ в интернет.

Основные каталоги изображений:

```text
Arts/
Bestiary/
```

## Версии и обновления

Каждая опубликованная версия сохраняется отдельным GitHub Release с тегом вида:

```text
v1.0.17
v1.0.18
v1.0.19
```

Это позволяет не обновляться сразу и при необходимости оставаться на более старой версии модуля.

Актуальные и предыдущие версии доступны в разделе **Releases** репозитория.

## Структура репозитория

```text
korshuns-compendium/
├── Arts/               # изображения предметов, портретов, баннеров и прочего
├── Bestiary/           # изображения существ и токенов
├── packs/              # LevelDB-компендиумы Foundry VTT
├── module.json         # манифест модуля
└── README.md
```

Установочный архив релиза содержит только необходимые для Foundry файлы:

```text
module.json
packs/
```
